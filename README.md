Forecast how many GTA VI players earn each trophy in week one. Round 3: a logit-scale trend plus counts model for live histories, and for frozen ones a refresh-state forecast in earner counts — the launch-night refresh to 3,868 players and 4,276 trophies earned is recovered from the competition's own published aggregates, so a frozen page is forecast as the refreshed page it is about to become, not as a dilution guess.
## Run it
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
